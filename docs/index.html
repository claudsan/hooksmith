☕ DE DEV PARA DEV

Nascido da frustração real com o WireMock e túneis na nuvem

Quem já desenvolveu integrações com gateways de pagamento, ERPs ou sistemas de mensageria conhece bem o sofrimento de testar webhooks localmente.

❌ O Sofrimento Antigo (WireMock & Túneis)

  • •O Dilema do WireMock: Dezenas de linhas em Java ou JSONs quilométricos de mapeamento e containers Docker pesados apenas para responder um simples 200 OK.
  • •A Cegueira do Terminal: Ficar olhando logs no console sem saber se o webhook chegou, se faltou header ou se o payload veio truncado.
  • •O Pesadelo Assíncrono: Criar scripts improvisados ou controllers fakes para simular um gateway que responde 200 OK e manda um POST de confirmação 3 segundos depois.
  • •Dependência de Túneis: URLs rotativas que mudam a cada reinício, limites de requisição e dados sensíveis trafegando em servidores de terceiros.

🔥 O Jeito Hooksmith

  • ✓Portas HTTP & HTTPS em 2 Cliques: Crie listeners locais com certificado SSL auto-assinado emitido automaticamente.
  • ✓Visibilidade Total em Tempo Real: Veja método, rota, status, tempo em ms, data/hora exata da chamada e payload com syntax highlighting.
  • ✓Callbacks Assíncronos Nativos: Configure na própria regra de mock a URL, método, delay e payload que o Hooksmith deve disparar após responder.
  • ✓Inspeção & Replay Instantâneo: Clique num mock para inspecionar seus detalhes, redimensione o painel Request/Response e formate JSON com 1 clique.

Manual Prático de Uso

Domine todo o fluxo de trabalho do Hooksmith em poucos minutos.

01

Criando e Gerenciando Listeners (HTTP & HTTPS)

Na barra lateral esquerda, clique em "+" em Listeners. Defina um nome amigável (ex: Gateway Pagamento), escolha a porta (ex: 4010 ou 8443) e marque a opção HTTPS/SSL se desejar criptografia local automática.

HTTP / HTTPS Zero-Config Self-Signed Cert Live Toggle
02

Monitorando o Live Traffic e Filtros

Toda chamada recebida aparece instantaneamente na coluna central com método, rota, status HTTP, latência e tag de origem (CAPTURED, MOCKED, REPLAY ou CALLBACK). Use a busca (Ctrl+K) ou os filtros rápidos.

CAPTURED MOCKED CALLBACK REPLAY
03

Inspecionando Payloads, Redimensionando e Formatando JSON

Ao clicar em uma requisição, o painel direito mostra a data e hora exatas da chamada. Arraste a barra divisória horizontal entre Request e Response para ampliar payloads extensos e use o botão "Pretty" para formatar JSON.

📅 Data & Hora Exatas ↕️ Split Redimensionável (50%/50%) ✨ Pretty / Raw JSON
04

Inspecionando e Editando Regras de Mock

Clique em um card em "Mock Rules" para visualizar todos os seus detalhes e comando cURL no Painel de Inspeção. Ao lado da porta, a tag SSL indica listeners seguros. Para editar, clique no ícone de lápis ou em "Editar Regra".

🔍 Mock Inspector (Read-Only) 🔒 Tag SSL por Porta ✏️ Edição Explícita
05

Configurando Callbacks Assíncronos Automatizados

Dentro do editor de Mock, ative "Callback Assíncrono". Informe o método (POST/PUT), a URL do seu backend local, o delay em milissegundos e o JSON do evento. O Hooksmith disparará o callback automaticamente após responder o mock.

🚀 Webhook Callback ⏱ Delay Configurável (ms) Payload JSON Customizado
06

Edit & Replay de Requisições

Selecione qualquer requisição capturada, clique em "Edit & Replay", ajuste o JSON ou cabeçalhos no editor Monaco e pressione Ctrl+Enter para disparar a nova chamada.

Monaco Editor Ctrl + Enter Save as Mock
